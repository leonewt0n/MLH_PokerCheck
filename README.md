# PokerCheck

PokerCheck is a multiplayer game that combines poker and checkers. Players share a game through [TigerDB](https://www.tigerdata.com/).

It was built for [Major League Hacking](https://mlh.io/) Hacktoberfest 2026.

## Stack

- React, TypeScript, and Vite
- TigerDB for multiplayer game data

Requires Node.js 24.

## Getting started

```bash
npm install
npm run dev
```

`npm run check` formats, lints, typechecks, builds, and runs tests.
